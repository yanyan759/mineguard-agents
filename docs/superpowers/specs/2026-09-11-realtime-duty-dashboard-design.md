# 实时值守前端改版设计

## 目标
将六智能体前端从技术验收式展示改成面向调度员的实时值守工作台，首屏直接呈现当前状态、决策建议、执行条件与审批状态。

## 方案
复用现有 React、Ant Design、WebSocket 与工作流数据结构，渐进改造 `App.tsx` 和结果展示组件。新增一个紧凑的最终结论摘要区，位于工作流结果详情之前；摘要从现有 `WorkflowResultResponse` 的感知、决策、资源、审批和反思结果中派生，不新增后端字段。

## 交互
摘要区展示风险等级、风险评分、推荐方案、下一步动作、资源可行性和审批状态。六 Agent 结果卡片继续保留并可折叠，作为证据详情。运行中显示当前 Agent 与实时状态，完成后切换到最终结论。

## 视觉
沿用现有深色煤矿控制台主题，强化风险色、信息层级和卡片间距；移动端保持单列布局。新增样式集中在 `styles.css`，中文注释说明关键决策。

## 验收
前端 TypeScript 构建通过；完成态能显示状态与决策建议；缺少部分 Agent 结果时摘要仍能安全渲染；现有启动、审批、取消、上传和 WebSocket 行为保持不变。
