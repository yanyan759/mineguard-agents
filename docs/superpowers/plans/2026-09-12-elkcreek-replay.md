# Elk Creek真实历史回放实施计划

**目标：**落实用户在来源研究后确认的真实历史回放，交付可复算输入、独立时间段评价和明确的适用性结论。属于阶段7已有算法验证工作的补充，仅修改agent1/。

**设计依据：**`docs/field-calibration-readiness-2026-09-12.md`及`docs/public-mine-parameter-evidence-2026-09-12.md`。用户已确认继续该路线；本计划由当前会话顺序执行，不再次请求实施许可。工作区无Git仓库，不执行提交。

**结构：**`services/historical_replay.py`负责目录选择/质量筛选、严格历史窗口、冻结参数与评价；`scripts/replay_elkcreek.py`负责读取现有ZIP、保存来源清单、执行全量回放及生成人类可读报告；`tests/test_historical_replay.py`负责独立手算边界用例。结果写入`output/validation/elkcreek/`，不修改在线服务与生产阈值。

## 执行前固定的方法

- 全部时间UTC。采用原作测区x=[9800,12800]、y=[4200,6500]、z=[1400,2100]米；RockSigma残差<80米、IMS<30米；剔除Reject和未知状态，无残差记录按原作允许但单独计数。
- 优先RockSigma；IMS仅补其起始日期前的数据及2012-12-02的00:00到07:00严格开区间。去除完全相同记录、报告同一时间冲突。按原始文件/行号追溯，不假定两个目录ID可互通。
- 预测输入不按事故标签豁免质量筛选；五次事故标签单独保存用于评价。作者的事后重处理目录不等于当时实时可获得资料，回放只保证事件时间无未来泄漏，不能冒称前瞻试验。
- 每个整点t仅汇总[t-1h,t)事件，频次=该小时目录事件数，最大能量按J计算。零记录窗表示目录没有记录，硬件在线状态及缺失率未知，不编造b值。
- 固定校准区间[2010-08-01,2010-10-30)，验证[2010-10-30,2013-02-01)。首次预测整点晚于区间起点1小时，保证输入窗属于对应区间。验证末尾24小时不计入窗口负例，避免右删失。
- 仅使用校准集的计数/最大能量各99%分位数（higher方法），严格大于任一阈值触发研究预警。不根据验证结果更改参数。此规则为软件研究基线，不是论文原有预警算法或矿方配置。
- 预警目标为(t,t+24h]内的五次已确认burst。报告窗口TP/FP/FN/TN、窗口precision/recall、报警窗口占比、连续报警段、无已知burst对应的报警段、事件命中/漏报与首次/最近提前量。FP仅指未对应这5个标签，不代表没有其他现场危险。
- 再报告始终报警的参考指标，防止高报警占比制造虚假的高事件命中率；置信度/生产有效性不由5例估计。始终报警不是候选现场策略。
- 当前simulation-v1七指标模型不满足输入口径，标记未评估，不用缺省b值或伪造数据强行让流程通过。

## 实际结果

专项测试9项通过；全量回放执行成功，质量筛选后197,778条事件，验证窗口19,776个。首90天冻结阈值为事件数>6或最大小时内单次能量>62,382.225509932425 J。

事件命中5、漏报0，但报警窗口占比41.64%，窗口precision仅0.83%（仅针对已知5次标签）。窗口TP68/FP8166/FN52/TN11490，1701个连续报警段中1685段未对应已知burst。该结果不足以支持部署或替换现行参数；没有根据验证结果调参。

另外直接重读原始ZIP，对5份事件前样本的全部75条记录逐条核对原始行、UTC时间、能量和窗口上下界，全部一致。源目录无完全重复、无同时间冲突；834条保留记录缺定位残差，硬件在线率未知。完整报告：`output/validation/elkcreek/report.md`。
