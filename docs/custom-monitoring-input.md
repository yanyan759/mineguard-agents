# 自定义监测任务验证

2026-09-12 修复：文本输入使用独立 custom 入口，解析指标后进入原有六 Agent 状态机。预设卡片继续选择对应 fixture，自定义输入不再套用黄色场景。

## 使用方式

在前端输入框粘贴下列文字，点击发送。正常输入只执行感知预警后结束；异常输入继续知识检索、调度、资源核算与管控；高风险建议暂停等待人工研判。记录同意意见不会下发现场动作，也不代表已核验操作人员权限。

### 正常输入（已实测：normal，0.075）

```text
MINE-001 / RDW-010 / 工作面-10：过去30分钟监测到2条微震事件，频次由1次/h升至2次/h，最大能量1000 J，b值由1.4降至1.3，数据缺失率0%。高能事件0条，空间集中比例0%。
```

### 黄色输入（已实测：yellow，0.4075）

```text
MINE-001 / RDW-011 / 工作面-11：过去30分钟监测到5条微震事件，频次由6.5次/h升至8次/h，最大能量18000 J，b值由1.15降至0.92，数据缺失率5%。高能事件0条，空间集中比例90%。支护工8/6人、锚杆400/180根、钻机3/2台。请给出风险评级、依据和处置建议，并核算这些资源是否满足所列需求。
```

资源数量格式为“可用/需求”。将支护工改为1/6人、锚杆改为0/180根、钻机改为0/2台，可验证资源不足与回退；未提供资源时结果为 unknown，不默认充足。即使所列数量全部满足，整体可行性仍为 unknown、执行条件仍未核验：尚需确认完整方案需求、人员资质、设备状态及现场库存。明确存在数量缺口时，可行性为 infeasible。

### 蓝色输入（本次实测：blue，0.195）

```text
MINE-003 / RDW-027 / 工作面-27：过去45分钟监测到4条微震事件，频次由3.2次/h升至6.4次/h，最大能量12500 J，b值由1.28降至1.19，数据缺失率3%。高能事件0条，空间集中比例35%。支护工7/5人、工程师1/1人、锚杆260/140根、液压支柱36/24根、钻机2/1台。
```

预期：六节点完成，建议30分钟内复查并现场核验（周期仍来自演示规则，需现场确认）；所列资源数量满足、整体执行条件未核验。知识结果展示官方原文链接及案例实际匹配词；置信度未评估、通知未发送、处置后效果未知。旧会话结果不会自动重算，请重新发送输入。

### 红色输入（已实测：red，暂停待人工审批）

```text
MINE-002 / RDW-020 / 工作面-20：过去30分钟监测到12条微震事件，频次由15次/h升至30次/h，最大能量300 kJ，b值由0.9降至0.4，数据缺失率2%。高能事件6条，空间集中比例95%。支护工8/6人、锚杆400/180根、钻机3/2台。请评估风险并列出处置建议和需人工审批的动作。
```

### 缺字段验证

输入“分析307工作面”，应提示补充缺少的指标，保留原文且可重新编辑；不会暗中启动黄色场景。

## 支持与边界

- 支持示例中的带单位中文指标及 MonitoringTask 同字段的 JSON；不是任意开放式问答解析器。
- 能量支持 J、kJ、焦耳、万J；频次支持次/h、次/小时；窗口支持分钟、小时；缺失率和空间比例使用百分数。JSON 的比例使用0～1。
- 高能事件数按当前规则的 >=50000 J 口径填写。缺少高能数、空间比例或起始指标时保持未知并提示评分依据不完整，不生成假事件或坐标。
- 资源支持支护工、工程师、应急队（人），锚杆、液压支柱（根），钻机（台），采用可用/需求格式。
- “实际参与评分的输入”显示解析后的数值；WebSocket 首个 workflow_start 事件也保存原文和 parsed_input。
- 当前使用 simulation-v1 演示阈值。数据进入真实程序计算，但不意味着阈值已经过矿井现场校准。
- 摘要缺少逐条事件、采样频率及处置后观测，不调用需要原始序列的预测模型，不声称风险下降或处置成功。结果标记初评及待核验事项。
- 自定义链路使用规则初评及本地可追溯文档检索。官方规程保留原文、来源链接、核对日期及适用条件；缺少或变更了已核对语料时返回缺项，不回退到模拟规程。参见[来源核查记录](evidence-source-verification-2026-09-12.md)。
- 案例为已整理的事故报告摘要，按关键词匹配；未逐篇核对原报告全文，明确标记待复核，不生成虚假的相似度分数。七个预设场景仍属模拟验证数据。
- 自定义结果的置信度、未核验权限、处置后风险及未评估效果使用 null；前端显示“未评估/未核验”，不以0或固定高分充当测量结果。
- 管控阶段仅记录建议、待通知岗位及人工研判意见；未接入真实通知、设备控制或可信身份认证，结果不能声称已经通知、授权或执行。
