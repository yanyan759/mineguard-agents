# 实际数据全链路接入：范围与验收

本文供维护者了解实际数据链路的实现范围与验证覆盖。首次配置请阅读 [实际数据配置指南](actual-data-guide.md)；本文中的测试记录用于解释验证范围，不代表已经连接任一矿井的生产业务系统。

## 设计

- 演示卡片保留 fixture；custom 的摘要与原始记录均使用实际数据节点，禁止调用 simulation-v1 或 fixture 库存/反思。
- 后端 SQLite 保存按矿井、巷道、测区隔离的不可变配置版本及资料。参数按监测窗口、时间和指标检查适用性。
- 上传资源 JSON/CSV 校验后解析；案例/规程/方案接受结构化 JSON 及可提取文本的 PDF/DOCX/TXT/Markdown。保存原件哈希、文本和来源。扫描件无可提取文本明确拒绝，禁止冒称已入库。
- prepare 接口统一处理摘要和原始记录，合并明确选择的台账，冻结参数和知识资料，run 保存快照与使用清单。后台与前端均不自行读浏览器旧配置。
- 知识节点引用已选资料；方案动作和需求来自结构化方案，普通正文只作引用依据，不猜测施工参数。
- 库存、身份、通知和回执复用业务 HTTP 契约；现场方案确认需可信身份与显式核验记录。通知/工单仅由用户显式触发。
- 原始观测比较保留父子关系和实际指标，不自动声称风险解除；置信度无验证模型时不伪造。
