## 一、总体策略：为什么这样分配

本项目最难替换的是 **监测预警阈值类参数**（能量/频次/b值分级、权重、复查间隔）。审计结论：

> **GB/T 25217.4-2019 只定义指标口径（频度/总能量/最大能量），不给出数值阈值。** 官方规程同样只写"预警临界指标由实测修订"的原则，不给数字。

因此阈值类参数采用 **三层策略**：

```
① 法规定框架   → 综合指数法分级 0.25/0.5/0.75、四色分级、高能事件 10⁴J/10⁵J
② 论文定区间   → 多矿现场标定案例汇总出"合理区间"，替换仿真单点值
③ 案例定形态   → 具体波形/时空形态（能量-频度曲线、b值下降轨迹）从案例论文提取
```

而 **业务规则类参数**（通知链/处置动作/角色权限/复查间隔）→ 从应急预案 + 规程条款 + 企业制度模板提取；**领域内容**（事故案例/规程条款/支护方案）→ 从学术论文 + 标准 + 导师资料提取。

### 每类建议存档格式

| 类别 | 推荐格式 | 提取要点 |
|------|---------|---------|
| 规程/预案 | HTML/PDF 原件 + 提取的 txt | 条文号、条款原文、时限数值 |
| 论文 | PDF 原件 + 提取的数值表 | **单位/计算窗口/监测系统型号** |
| 标准 | PDF 原件 | 标准号、版本年、关键数值条款 |
| 数据集 | ZIP（Elk Creek） | README + 目录结构 |

### 爬取通用注意事项

1. **编码**：中文网页保存为 UTF-8；PDF 用原文。
2. **反爬**：chinamine-safety.gov.cn / mem.gov.cn 有 SSL/反爬 → 浏览器直访，找底部 PDF 附件。
3. **版本核对**：MT 系列 2025 换版、GB/T 35056 有 2018/2023 两版 → 用 std.samr.gov.cn 核对现行性。
4. **付费墙**：知网/万方/维普 → 优先 chinacaj.net / NSTL / 各刊官网 / 百度学术镜像。
5. **每个数值参数记录来源**：替换进 config 时注明「出处矿井 + 论文 + 单位 + 窗口」。
