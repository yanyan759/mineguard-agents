# 现场参数来源与当前系统可用性核查

核查日期：2026-09-12。范围为既有六智能体系统的参数依据与真实数据验证，不修改现行评分参数，不把公开论文自动登记为矿方批准配置。

## 结论

公开来源可以支持方法选择、候选初值和历史数据回放，但目前没有取得适用于用户所输入 MINE-003 / RDW-027 的矿井批复参数和验证记录。输入数字经过真实程序计算，与预警结论已经现场验证，是两件需要分别证明的事。

当前自定义输入得到的0.195是 simulation-v1 的加权规则分数，不是19.5%的事故概率，也不是现场验证指标。本次没有替换线上评分规则。公开案例与数据集的具体核查见[数据来源研究](public-mine-parameter-evidence-2026-09-12.md)。

后续执行记录：用户确认后，已完成独立双指标研究基线的真实目录回放，见[实际回放报告](../output/validation/elkcreek/report.md)。197,778条筛选后事件、19,776个验证窗口；5次事件命中，但报警窗口占41.64%、窗口precision仅0.83%，不足以支持现场采用。当前七指标模型仍未验证，没有自动更换线上参数。

## 已在线核对的官方依据

### 现行《煤矿安全规程》第三百三十五条（四）

来源：[中国政府网国务院公报全文](https://www.gov.cn/gongbao/2025/issue_12326/202510/content_7043684.html)，本次HTTP 200；2026-02-01起施行。

> 应当根据现场实际考察资料和积累的数据确定冲击地压危险预警临界指标。

这要求现场依据。该条没有给出适用于所有矿井的微震能量、b值、频次五色分界。

同章第三百三十八条要求在防冲预测图中标注能量大于10⁴ J的微震事件位置。此数值是该条规定的制图标注条件，不能转换成任意工作面“达到10⁴ J即黄色/红色”的预警阈值。

### 2026版《防治煤矿冲击地压细则》：已发布，核查日尚未生效

来源：[国家矿山安全监察局印发通知，矿安〔2026〕82号](https://www.chinamine-safety.gov.cn/zfxxgk/fdzdgknr/tzgg/202607/t20260724_677906.shtml)，2026-07-22印发、2026-07-24网页发布；[官方PDF全文](https://www.chinamine-safety.gov.cn/zfxxgk/fdzdgknr/tzgg/202607/W020260724567567627285.pdf)。通知和PDF本次均HTTP 200，返回内容可正常解析为PDF，本地附件SHA256与在线下载字节一致。

第二十七条关键原文：

## 当前程序的实质差距

| 项目 | 代码事实 | 对“真实可用”的影响 |
| --- | --- | --- |
| 阈值与权重 | `config/warning_thresholds_v1.py` 说明数值依据fixture设计，含7项特征权重及五色等级边界 | 替换一个能量阈值不能验证整套加权模型；需要方法与参数整体来源 |
| 统计窗口 | `services/perception_warning_service.py` 的摘要评分直接使用用户提供的事件数、频次、b值等；窗口长度未用于修正事件数严重度 | 不同窗口的事件数不能直接共用未经验证的同一阈值；论文的日尺度阈值不能直接用于45分钟摘要 |
| b值含义 | 摘要只有首末b值，缺少估计方法、样本量、完整性阈值、拟合区间及历史窗口 | 两个端点能描述净变化，不能独立证明“持续下降”或复现某篇论文的b值预警 |
| 能量趋势 | 摘要只有窗口最大能量，没有之前窗口的能量序列；现有标签却含“异常升高” | 可核算数值和按选定规则比较，不能仅凭最大值证明时间上升趋势；需后续修正语义或补充基线 |
| 原始模型 | 自定义摘要不调用需要原始序列的MOA-Transformer；已有模型接口仅作可选预测增强 | 不能对外声称自定义六节点结果经过了真实训练模型验证 |
| 灾害适用性 | 当前主要指标为微震，项目目标还包括喀斯特顶板灾变 | 冲击地压论文不能独立证明普通冒顶、离层水或喀斯特塌陷预测有效，需区分灾害与补充监测 |
| 验证指标 | 软件回归证明流程及计算实现；没有目标矿井独立时间段标签与误报/漏报统计 | 通过单元测试不等于预警准确率达标，也不能把无事故记录自动当成所有时刻安全 |

本表为只读调查发现，尚未实施新评分模型或扩大现有数据输入契约。

## 可落地的验证顺序

1. 先选一份具有公开原始事件与已确认结果的数据集，保留来源、时间、单位、设备、采区、许可与文件哈希。历史事故说明与事件目录分开保存。
2. 按该数据集及已选方法定义统计窗口、能量口径、b值估计和完整性要求。原数据缺少J单位能量或b值时保留缺失，不编造字段以迎合现有输入框。
3. 用事故发生前可获得的数据生成输入，用之后已确认的结果验证；校准与验证按时间分离，避免把事件发生后的最大能量作为预警证据。
4. 报告有明确定义的命中、漏报、误报、提前量及样本范围。不把五次事故全部用于调参后再宣称独立验证通过；小样本只报告其实际覆盖范围。
5. 对任意自定义输入先检查方法适用性。满足条件时给出计算、阈值来源、触发依据和辅助建议；不满足时明确哪些结论不能作出、还缺什么数据。
6. 若用于具体矿井，需取得同矿井/工作面条件的参数与批复记录，或完成现场数据校核。通用法规可用于核验要求，但不能替代阈值有效性的证明。

“每次输入都有真实结果”可验收为：每次计算与证据都可复核，适用时给出结论，不适用时给出确定的缺项和适用性结果；不能验收为无论输入多少信息都必须输出一个确定的安全等级。
