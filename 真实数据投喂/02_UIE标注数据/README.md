# 知识抽取标注数据

本目录提供知识抽取模型使用的 CSV/JSONL 模板和示例。它用于离线训练或评估，不是提交监测任务的必需资料。标注内容必须来自已获授权、已脱敏的原文。

## 文件

| 文件 | 说明 |
| --- | --- |
| `标注模板_空.csv` | 可直接复制的空模板 |
| `标注示例_真实报告10条.csv` | 十条格式示例 |
| `标注示例_真实报告10条.jsonl` | 同一批示例的 JSONL 形式 |
| `合并新标注.py` | 合并和去重工具 |

## CSV 格式

表头必须为：

```text
text,entity,entity_type,relation,object,object_type,confidence,source
```

字段要求：

- `text`：包含目标信息的原文，一至三句为宜。
- `entity`、`relation`：可留空；如果填写，必须能由原文支持。
- `object`：必填，且必须逐字出现在 `text` 中。
- `entity_type`、`object_type`：使用项目规定的实体类型。
- `confidence`：0 到 1 的人工标注可信度；不确定时留空比填写猜测值更好。
- `source`：原始文件名、报告编号或来源记录中的名称。

实体类型：地质构造、支护设备、顶板灾变、监测指标、处置规程、岗位角色、巷道分区。

关系类型：诱发、支护、防控、监测、调度、上报、传导。

## 标注检查

提交前检查以下内容：

1. `object` 在 `text` 中逐字出现。
2. 数值带单位，原文没有的数值不补写。
3. 同一文档中的实体类型和名称保持一致。
4. `source` 可以回到原始文件和来源登记。
5. 文件使用 UTF-8 编码，并且没有个人凭据或未脱敏信息。

## 使用方式

标注文件供离线整理或自行配置的模型训练、评估使用。当前前端资料配置框不提供 UIE 标注上传或训练按钮；保存到本目录也不会自动启动训练。

合并工具通过 `MINEGUARD_UIE_CSV` 读取已有 CSV，通过 `MINEGUARD_UIE_NEW_JSON` 读取新增 JSON 数组（不是 JSONL），并覆盖写回已有 CSV。先准备副本，再设置这两个变量；脚本默认指定的批次文件不随仓库提供。人工标注可信度只说明标注质量，不是系统风险评估的模型置信度。

目录中的合并脚本只处理本地文件，不会自动抓取网页。运行实际数据工作流时，优先阅读 [`docs/actual-data-guide.md`](../../docs/actual-data-guide.md)。
