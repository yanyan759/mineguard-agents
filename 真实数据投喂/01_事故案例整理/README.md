# 01_事故案例整理 —— 投喂说明（任务一）

## 定位

基于本地事故通报资料（`agent1/煤矿资料收集/05_近五年煤矿顶板事故通报/` 20 份）整理的**真实事故案例库**，并经山东局官网直链补充 2 份较大事故完整报告（新安/羊泉）、国家矿山安全监察局官网补充 2 份重大事故完整报告（担水沟/红阳三矿）。

**产出链路**：
1. **Claude 侧独立解析**：本地并行 agent 读取报告原文逐字段提取（`事故案例_真实报告V1.yaml`，16 份，严禁编造）
2. **codex 侧数据包**：`任务成果/01_事故案例整理/`（22 份草稿 + source_url / published_at + 2 份重大 PDF + 质量报告）
3. **交叉整合**：
   - `_整合脚本.py` → V1（17 份：16 份正文 + 金刚 blue + codex URL）
   - `_整合脚本V2.py` → 并入 2 份重大（red）逐字解析（担水沟/红阳三矿，2017 年）
   - `_整合脚本V3.py` → 并入 2 份较大（orange）逐字解析（新安煤业 2021 / 羊泉矿业 2022，山东局完整报告）
   - 最终 **`事故案例_真实报告FINAL.yaml`（21 份）**

## 数据统计（FINAL，21 份）

- **年份分布**：2017×2 / 2021×2 / 2022×6 / 2023×5 / 2024×3 / 2025×3
- **风险等级**：red（重大）×2、orange（较大）×4、yellow（一般）×14、blue（涉险）×1
  - red：担水沟（2017-01-17，10 死）、红阳三矿（2017-11-11，10 死）—— 均按原报告保留冲击地压属性
  - orange：凤凰台（2022）、钱家营（2024）、新安煤业（2021-05-26，3 死）、羊泉矿业（2022-06-05，3 死）
- 每份均含 `source_url`（官方发布页/PDF）与 `published_at`
- 覆盖语料：断层/采空区/二合顶/孤岛煤柱/冲击地压/再生顶板等地质构造，锚杆/锚索/单体支柱/液压支架/π型钢梁/临时支护等支护设备，冒顶/片帮/漏顶/网兜/伞檐/冲击地压等顶板灾变 —— 均可作 UIE 标注与图谱实体语料

- **2 份 red 事故发生于 2017 年，超出"近五年"**：因验收需真实红色案例覆盖而保留，`risk_level_original` 与原报告表述一致（担水沟"冲击地压引起的重大顶板事故"、红阳三矿"重大顶板（冲击地压）事故"），不做任何改标。
