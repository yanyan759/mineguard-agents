# 资料导入模板与示例

本目录提供 MineGuard Agents 的离线案例整理资料、标注示例和开发者工具。普通用户使用前端“矿方资料与参数配置”框下载上传模板；本目录的 YAML 和标注文件不能直接作为前端上传模板。

## 目录说明

| 目录 | 内容 | 主要用途 |
| --- | --- | --- |
| `01_事故案例整理/` | 案例 YAML、来源映射和整理脚本 | 知识检索与历史案例回放 |
| `02_UIE标注数据/` | CSV/JSONL 模板和标注示例 | 知识抽取训练或离线评估 |

## 推荐使用流程

1. 阅读 [`资料准备与导入规范`](../docs/真实资料爬取与整理要求清单.md)，确定字段、格式和来源记录要求。
2. 在前端下载知识、方案或资源模板，使用已获授权的资料填写。需要参考本目录案例时，将核对后的正文及出处整理成 `text` / `terms` 知识 JSON。
3. 在前端资料配置页面上传并校验文件，确认状态为“已入库”。
4. 保存包含矿井、测区、版本和有效期的配置，再启动自定义实际数据任务。
5. 在运行结果中检查资料名称、SHA-256、配置版本和 evidence/provenance。

## 目录中的脚本

案例目录和标注目录中的 Python 脚本用于格式转换、合并和本地校验。脚本根据自身位置定位仓库，不依赖开发者电脑的绝对路径。它们不会自动获取外部网站，也不会替用户确认资料的真实性或分发权限。

如果资料存放在仓库外，可按脚本说明设置 `MINEGUARD_REFERENCE_DATA_DIR`、`MINEGUARD_UIE_CSV` 或 `MINEGUARD_UIE_NEW_JSON`。这些变量只影响离线整理，不会自动导入前端配置。合并工具可能覆盖目标文件，使用副本操作；不向公共仓库提交本机路径或凭据。

## 资料状态

配置框中的“已上传”“已校验”“已入库”表示支持格式的文件已解析保存；“已用于 N 次运行”及运行编号来自实际使用记录。核对某次使用情况时查看该运行的 evidence/provenance。这些状态不适用于本目录的离线标注文件。

文件格式通过不等于现场参数已经标定。矿井阈值、岗位权限、库存可用量和执行回执仍需由有权限的业务系统或人工核验提供。
