# 资料导入模板与示例

本目录提供 MineGuard Agents 的字段说明和空模板。公开仓库不保存真实事故报告、矿井监测数据或未脱敏标注；普通用户使用前端“矿方资料与参数配置”框下载上传模板，本目录文件不能直接作为前端上传模板。

## 目录说明

| 目录 | 内容 | 主要用途 |
| --- | --- | --- |
| `01_事故案例整理/` | 字段说明和来源登记格式 | 用户在本机整理已授权案例 |
| `02_UIE标注数据/` | CSV 空模板和字段说明 | 用户在本机整理脱敏标注 |

## 推荐使用流程

1. 阅读 [`资料准备与导入规范`](../docs/真实资料爬取与整理要求清单.md)，确定字段、格式和来源记录要求。
2. 在前端下载知识、方案或资源模板，使用已获授权且已脱敏的资料填写。需要参考公开案例时，将核对后的正文及出处整理成 `text` / `terms` 知识 JSON。
3. 在前端资料配置页面上传并校验文件，确认状态为“已入库”。
4. 保存包含矿井、测区、版本和有效期的配置，再启动自定义实际数据任务。
5. 在运行结果中检查资料名称、SHA-256、配置版本和 evidence/provenance。

## 外部整理

真实资料的格式转换、脱敏和来源核验应在部署方的受控环境完成，再通过前端配置页面上传。生成的真实案例、来源映射和标注数据应留在本地或受控资料库，不提交到公开仓库。

## 资料状态

配置框中的“已上传”“已校验”“已入库”表示支持格式的文件已解析保存；“已用于 N 次运行”及运行编号来自实际使用记录。核对某次使用情况时查看该运行的 evidence/provenance。这些状态不适用于本目录的离线标注文件。

文件格式通过不等于现场参数已经标定。矿井阈值、岗位权限、库存可用量和执行回执仍需由有权限的业务系统或人工核验提供。
