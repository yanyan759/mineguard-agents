# 煤矿安全资料索引

本目录保存 MineGuard Agents 可引用的公开参考资料及其来源索引，覆盖法规制度、应急预案、顶板和冲击地压技术、支护、事故案例、监测研究与专家经验。资料用于知识检索、方法说明和离线回放；它们不自动构成任何矿井的生产阈值、审批权限或现场方案。

## 使用方式

1. 先按主题打开对应目录的 `清单.md`，查看文件名称、发布机构、版本、来源地址和资料状态。
2. 选择已获授权、适用范围明确的资料，按 [`docs/真实资料爬取与整理要求清单.md`](../docs/真实资料爬取与整理要求清单.md) 的格式上传到配置页面。
3. 保存矿井、测区、有效期和资料版本，再运行自定义实际数据任务。
4. 在结果的 `evidence` 和 `provenance` 中检查本次实际引用的文件和哈希。

## 来源和适用性

- 清单中的 URL 指向原始发布机构、期刊或公开索引；网页可能改版，仓库内原件以文件哈希为准。
- 论文和公开案例的参数只在其原研究对象、单位和统计窗口内成立。跨矿使用前必须由矿方确认并形成新的配置版本。
- 企业制度和应急预案反映发布单位的职责安排，不能直接推导其他单位的权限矩阵。
- 公开资料没有实时库存、人员资质、设备状态和执行回执。上述信息需要通过配置页面或业务接口提供。
- 受访问权限、版权或页面变更影响而无法提供全文的条目，会保留题录和来源说明；这类条目只能作为检索线索，不能冒充已入库全文。

## 文件与脚本

各目录中的 PDF、HTML、TXT 和来源清单组成参考资料包。`_download.py`、`_inspect*.py`、`_cleanup.py` 等脚本仅用于本地下载、整理和检查，运行前应确认访问权限和分发许可。不要把个人账号、Cookie、令牌或业务凭据写入脚本或提交到仓库。

资料导入的字段、状态和校验流程见 [`真实数据投喂/README.md`](../真实数据投喂/README.md)。
