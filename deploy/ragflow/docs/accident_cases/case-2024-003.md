# 事故案例：case-2024-003

- **事故位置**：ZZ煤矿东三采区3301工作面
- **发生时间**：2024-01-10T22:45:00
- **风险等级**：yellow
- **案例来源**：煤矿矿压观测年报

## 致灾因素
- 采空区悬顶面积过大
- 周期来压与地质构造叠加

## 前兆特征
- 液压支架阻力周期性升高但峰值稳定
- 微震事件频次小幅升高（3→8 次/小时）
- b 值维持在 1.1-1.2 正常范围

## 处置措施
- 加强矿压观测频次
- 调整放顶煤工艺参数
- 提前准备备用支护材料

## 处置结果

顺利通过周期来压，未发生事故。属于常规操作，方案有效。

## 事故教训
- 支架阻力周期性波动是正常的来压特征，需与异常升高区分
- b 值稳定是重要安全信号，可降低不必要的应急响应
- 提前准备备用材料和平稳过渡是低成本有效处置
