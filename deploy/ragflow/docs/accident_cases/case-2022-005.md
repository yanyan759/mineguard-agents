# 事故案例：case-2022-005

- **事故位置**：YY煤矿北二采区2205工作面
- **发生时间**：2022-08-20T09:15:00
- **风险等级**：orange
- **案例来源**：冲击地压典型事故案例选编

## 致灾因素
- 邻近断层活化
- 微震活动沿断层面集中分布
- 未及时加密支护

## 前兆特征
- 微震事件沿断层走向呈条带分布
- 事件能量逐次递增（5000→15000→45000→80000J）
- 断层附近钻孔应力计读数异常升高

## 处置措施
- 工作面停产
- 补打锚索加密支护
- 施工卸压钻孔

## 处置结果

停产 3 天后恢复，未发生冒顶。卸压钻孔有效释放了断层附近的集中应力。

## 事故教训
- 微震事件沿构造呈条带状分布是断层活化的重要特征
- 能量逐次递增模式应触发快速响应，不应等待完整预测窗口
- 卸压钻孔在断层活化情况下比加密支护更有效
