# 事故案例：case-2021-008

- **事故位置**：WW煤矿西翼采区1502工作面
- **发生时间**：2021-11-05T03:20:00
- **风险等级**：red
- **案例来源**：煤矿重大险情案例汇编

## 致灾因素
- 喀斯特溶洞塌陷引发连锁微震
- 顶板岩层整体失稳
- 前期微震信号被误判为正常矿压

## 前兆特征
- 微震源深度突然从 -350m 跳变到 -280m（溶洞层位）
- b 值从 1.4 急降 0.25（1 小时内）
- 事件频次跳跃式增加（3→15→30 次/小时）
- 多台支架同时报警压力异常

## 处置措施
- 紧急全矿撤人
- 启动矿级应急预案
- 地表钻孔探查溶洞发育范围

## 处置结果

人员成功撤离，但工作面部分坍塌，停产 45 天。事后分析为喀斯特溶洞顶板突然塌陷。

## 事故教训
- 震源深度突变是喀斯特地区特有的高危前兆
- b 值急降（>0.2/h）应直接触发最高级别告警
- 多传感器同时异常时不应等待人工研判，应自动启动撤人流程
